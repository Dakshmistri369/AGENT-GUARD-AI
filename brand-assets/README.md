# AgentGuard AI — Brand Identity & Logo Assets

This directory contains the transparent logo and branding assets generated from the original concept art.

## Color Palette
- **Electric Blue**: `#0072FF` / `#3B82F6` (Border left, primary badge accents)
- **Cyan / Neon Teal**: `#00D2FF` / `#2DD4BF` / `#14B8A6` (Orbit ring, padlock, "Guard" text)
- **Deep Navy Background**: `#050D1A` / `#0A1628` (Web application background)
- **Pure White**: `#FFFFFF` ("Agent" and subtitle text)
